# 2026-11-06 — Tharanga: #254, staff account recovery

Third of the in-scope features (after #253 → PR #277, #262 → PR #278). No migration.

## Done (branch `feature/254-staff-account-recovery`)

- `POST /api/admin/users/{id}/reset-password` `{ temporaryPassword }`, `/unlock`, `/reset-two-factor`. `Users.Manage` at
  the route as every staff write; the handler (`RecoverStaffAccountCommandHandler`) then requires a **Super Admin**,
  **before it reads the target** (one answer for a real id and a missing one — #101's lesson). Never on oneself; never a
  **protected** account; a **guarded** account only from a protected one (a reset that sets the password and removes
  the authenticator is a takeover of that account, so #255's deactivate rule applies here although it did not to roles).
- Store (`StaffUserRoleManagementStore.RecoverAccountAsync`): the existing skeleton — execution strategy, clean
  tracker, transaction, per-user `sp_getapplock`, fresh read, `UserManager`, audit enlisted, one commit.
  - Reset password leaves a **known temporary password** (the forced change asks for the current one), sets
    `MustChangePassword`, clears the lockout, rotates the stamp (sessions end at their next request).
  - Unlock clears `LockoutEnd` + `AccessFailedCount`; `changed=false` when not locked.
  - Reset 2FA = `AdminTwoFactorManager.DisableAsync`'s recipe: flag off, **key replaced** (setup resumes an existing
    key), no recovery codes, stamp rotated; a Super Admin is then confined to re-enrolling.
- Audit: `AdminPasswordReset`, new `StaffUnlocked`, `TwoFactorReset` — EntityType User, EntityId target, flags only;
  never the password, key, codes or failed-attempt count (DB24).
- Staff detail gains `lockedOutUntilUtc` and `twoFactorEnabled` (flags/time only). Admin user page: **Account
  recovery** section for a Super Admin (not self, not protected, not locked-for-viewer): temporary password box with the
  password rule and "in person or by phone"; Unlock when locked; two-step Reset two-factor naming the address.
- Docs: doc 11 P14 steps 5/7/8, the screen table and the StaffInvite note; admin guide (access, help).
