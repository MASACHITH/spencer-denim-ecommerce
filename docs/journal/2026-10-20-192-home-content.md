## 2. What was built

**Backend** (`Content.View/Create/Edit/Delete`, one per route; antiforgery; whole-form bodies — a missing key
is a 400 naming it):

- `GET/PUT /api/admin/content/home…` — all ten blocks with a **block-rule table** sent to the screen
  (`HomeBlockRules`: which section and item fields a block uses, which are required, how many items, whether a
  link may leave the site). A field a block does not use must be null, so a video on a benefit is refused by
  name instead of stored and ignored. Items have no row version of their own, so **the section is the
  aggregate**: item writes send and move the section's row version.
- Media slots take a media-library **public id** (upload first, as the settings logo does); the asset must be
  a ready, public image (with alt text) or video. A hero video needs a still. Usage rows are rewritten in the
  same transaction (`HomeSectionItem` / `SizeGuide` owners; new role `MobileImage`).
- Links: a path on this site (resolved against a base, so `//host`, `\`, control characters and every scheme
  but http(s) fail), or a full http(s) address with no credentials where the block allows it (social only;
  announcements). A product row's listing must be one the catalogue can answer (`ProductListQuery.Create`).
- Plain text is stored as typed and rendered by interpolation; control characters (line breaks) refused.
- Audit: field diffs (`HomeSection`, `HomeSectionItem`, `AnnouncementMessage`, `SizeGuide`); an untouched
  resave writes no row. Size-guide HTML is recorded by length, the table by shape.
- **Every content write calls `IHomePageCache.Evict()`** after its save — including content pages. Sale
  campaigns are #191's branch and were not touched.
- Announcements have no `rowversion` column; the version token is `UpdatedAtUtc ?? CreatedAtUtc` to the
  millisecond (read back after save, because `datetime2(3)` rounds). It catches the stale-form case; it cannot
  close a race of a few milliseconds that a real row version would. Recorded, not migrated.

**#70** — `SizeGuideTableInput`: input ≤ 128 KiB before parsing; columns ≤ 20, rows ≤ 100 and **columns × rows
≤ 1,000 checked from `GetArrayLength` before anything is sized**; every row exactly as wide as the headings;
cells strings or numbers ≤ 60 chars; unpaired surrogates refused in both spellings; stored canonically. The
bounds are pinned inside the read path's 40 × 200. `IntroHtml` and `MeasuringTipsHtml` go through
`HtmlSanitiser`; what was removed is returned and shown; images need alt text; ≤ 20,000 chars after cleaning.

**#37** — `HomePageCache.SetPage(page, validUntilUtc)`: the entry expires at the earlier of 5 min and the next
`StartsAtUtc`/`EndsAtUtc` ahead among switched-on sections and items (four small `MIN` queries, on a cache miss
only, measured from the instant *before* assembly so it can only expire early). A boundary already due is not
cached at all. The allowance is now a row in **docs/08 §7.4**.

**#63** — the hero, both banners, four trending and six social rows (words and links, word for word what the
importer wrote) are seeded by `HomeContentSeeder` **switched off**, offered **once** by version
(`Seed.HomeContentVersion` = 2, the #152 rule), never over an existing row. The retraction of the importer's
old "Activewear" words moved with them: field by field, exact match only, applied once. The importer now only
finds the row waiting at a slot, attaches the picture and switches the row on (and its section, as before); it
no longer invents a row (a missing one fails the run and names the fix). Fresh database: the storefront
renders exactly what it did (artwork sections are off).

**#36** — `<sd-site-header>` publishes its own rendered height as `--header-height` from a `ResizeObserver`
(rounded up); the token stays as the server render's value. Guard moved to a new
`storefront-header-height.e2e.ts`, driven from the stub's admin-set strip (`long` 200-char, `empty`, `single`,
`default`) at all eight widths, stepping **every** message of the rotation with the bar's own Next button.

**Admin screens** (sub-agent, reviewed): Homepage, Announcement bar, Size guides list + editor, media picker,
dashboard links. Screenshots in `2026-10-20-192-home-content/`.
